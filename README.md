# Complete Academy

**Mobile companion for FNB App Academy learners across Africa.**

Built for the FNB App of the Year Awards — targeting:
- Best Educational Solution
- Best African Solution
- Most Innovative Solution
- Best Consumer Solution

## Features (MVP)

- Offline-first lesson modules aligned to Academy curriculum
- Interactive JavaScript code playground
- Progress tracking, points & streaks
- Badges and African leaderboard (demo)
- Certificate generation
- AI Study Buddy (mock responses)
- Mobile-first PWA design matching App of the Year / FNB teal theme
- Fully client-side (localStorage) — works offline after first load

## Demo Account

Click **"Try Demo Account"** on the landing page, or use any name on the login screen.

## How to run locally

Just open `index.html` in a modern browser, or use any static server:

```bash
npx serve .
# or
python3 -m http.server 3000
```

## Deploy (today)

1. Create a new GitHub repository named `complete-academy`
2. Push this folder
3. Connect to **Vercel** (or Netlify / Cloudflare Pages) → automatic deploy
4. You get a public URL in under 2 minutes

## Tech

- Vanilla HTML / CSS / JS
- Tailwind CSS (CDN)
- localStorage for progress
- No backend required for MVP
